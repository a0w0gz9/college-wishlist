         FIREBASE SETUP FOR COLLEGE WISHLIST
              Follow These Steps (15 minutes)
===============================================================

FIREBASE ALLOWS:
✓ Friends/family claims to sync in real-time

===============================================================
STEP 1: CREATE FIREBASE PROJECT
===============================================================

1. Go to: https://console.firebase.google.com
2. Click "Create a project"
3. Project name: "college-wishlist"
4. Click "Continue"
5. Uncheck "Enable Google Analytics" (optional)
6. Click "Create project"
7. Wait for it to finish (~1 minute)

===============================================================
STEP 2: CREATE REALTIME DATABASE
===============================================================

1. In the left sidebar, click "Realtime Database"
2. Click "Create Database"
3. Location: "us-central1" (default is fine)
4. Security rules: Start in "Test Mode" (for now)
5. Click "Enable"

Wait for it to initialize...

===============================================================
STEP 3: GET YOUR FIREBASE CONFIG
===============================================================

1. In left sidebar, click "Project Settings" (gear icon)
2. Go to "General" tab
3. Scroll down to "Your apps" section
4. Click "</> Web App"
5. Give it a name: "college-wishlist"
6. Click "Register app"
7. You'll see a config object that looks like:

   const firebaseConfig = {

     projectId: "your-project-id",

8. COPY THIS ENTIRE CONFIG

STEP 6: UPDATE SECURITY RULES (IMPORTANT!)
===============================================================

Now we need to set proper security rules so:
✓ Anyone can submit claims
✓ Only you (admin) can see notes
✓ Public can see items

1. Go to: https://console.firebase.google.com
2. Click your project (college-wishlist)
3. Left sidebar → Realtime Database
4. Click "Rules" tab
5. Replace ALL the text with:

{
  "rules": {
    "claims": {
      ".read": false,
      ".write": true,
      "$uid": {
        ".validate": "newData.hasChildren(['name', 'item'])"
      }
    },
    "items": {
      ".read": true,
      ".write": false
    },
    "admin": {
      ".read": "root.child('users').child(auth.uid).exists()",
      ".write": "root.child('users').child(auth.uid).exists()"
    }
  }
}

6. Click "Publish"
